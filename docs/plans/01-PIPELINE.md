# 제약·바이오 전문기자 대학원 준비 학습 앱 기획안 (v1.0)

> 작성일: 2026-11-22
> 대상 AI: 이 문서를 읽고 (1) 학습 콘텐츠(교과서·개념서·문제집·모의 인증시험서)와 (2) 매일 쓰는 HTML 학습 앱을 만드는 AI
> 문서 사용자: 건강의학 전문기자 → 제약·바이오 산업 전문기자로 전환 중인 학습자 (이하 ‘학습자’)

## 0. 이 문서를 읽는 AI에게 (필독)

- 이 문서는 하나의 제품 명세서다. 섹션 번호를 근거로 작업하고, 모호한 부분은 섹션 15의 기본값을 따른다.
- 작업은 두 갈래다.
  - 트랙 A — 앱 개발: 섹션 8~11, 13을 구현한다.
  - 트랙 B — 콘텐츠 생성: 섹션 4~6, 12, 14의 템플릿으로 주차별 콘텐츠 팩을 만든다.
- 한 번에 전부 만들지 않는다. 앱은 섹션 13의 마일스톤 순서대로, 콘텐츠는 주차 단위 팩으로 나눠 생성한다.
- 사실 정확성이 최우선이다. 규제·약가·수치처럼 바뀌는 정보에는 출처와 기준일을 붙이고, 확신이 없으면 needsVerification 표시를 한다 (섹션 12.6).
- 실제 기업의 미확인 정보를 지어내지 않는다. 연습용 사례는 가상 기업(예: 가온바이오, 한빛제약)으로 만든다.

## 1. 프로젝트 개요

### 1.1 한 줄 정의
건강의학기자가 제약·바이오 산업 전문기자로 성장하기 위해, 제약산업 특성화대학원 입학 전에 약학·생명과학·경영 전공 동기들에게 뒤처지지 않는 수준까지 끌어올리는 36주 자기주도 학습 시스템.

### 1.2 최종 목표 (North Star)
기업의 발표를 가장 잘 ‘전달’하는 기자가 아니라, 가장 잘 ‘이해하고 해석’해 독자에게 전하는 기자.

### 1.3 이 시스템이 해결할 문제
1. 범위가 넓다: 생명과학·약리·임상통계·규제·약가·재무·특허·저널리즘 윤리를 함께 다뤄야 한다.
2. 잊는다: 직장인은 학습 간격이 불규칙해 망각이 빠르다.
3. 실전과 끊긴다: 개념을 알아도 보도자료·공시·학회 데이터 앞에서 판단이 안 된다.
4. 기준이 없다: 동기 대비 내 수준이 어디인지 모른다.

### 2.1 학습자가 갖춰야 할 3대 전문성 (모든 콘텐츠의 분류 축)
1. 과학적 이해력 (science): 신약의 작용 원리, 임상시험 단계, 결과의 실제 의미 판단
2. 산업적 이해력 (industry): 파이프라인, 기술수출, 특허, 경쟁, R&D, 시장 규모, 기업 전략
3. 미디어·기업 관계 이해력 (media): 홍보성 주장과 실제 성과 구분, 이해관계 속 기사 독립성 유지

모든 개념 카드·문제에는 이 3축 중 하나 이상을 태그한다 (axis: 'science' | 'industry' | 'media').

### 3.3 학교별 커리큘럼에서 역산한 ‘선행 필수 개념’
- 성균관대 대비: 의약품 인허가 절차(국내·FDA·ICH CTD), 경제성평가 기초(QALY·ICER), 보험약가 제도, 약물역학 개론, 임상시험 설계·관리, 특허 전략, 기술가치평가(rNPV), 바이오벤처 재무(유상증자·IPO), GMP·시판후 안전관리 개요
- 연세대 대비: 기초 통계와 의약통계(회귀·생존분석 개념), 임상시험 디자인·자료분석, 약물역학 연구방법론, 경제성평가 방법론, 바이오의약품·제조품질(GMP) 개요, 의약 빅데이터 개념
- 동국대 대비: 약무정책, 바이오의약품 허가제도와 허가 사례, 품질관리, R&D·빅데이터·AI 활용, 재무회계, 사업개발·전략적 제휴(라이선싱 계약 구조)
→ 세 곳의 공통분모가 섹션 5 커리큘럼의 뼈대다.

### 3.4 지원 전 반드시 직접 확인할 것 (앱의 ‘입시 체크리스트’ 화면에 그대로 구현)

2. 수업 캠퍼스 위치 (학과에 따라 서울 외 캠퍼스 수업 가능성)

4. 전형: 서류 + 면접/구술시험 (구술 범위, 영어 질문 여부)
5. 등록금·장학 조건 (전일제/시간제 차이)
6. 졸업 요건: 논문 또는 대체 과제, 외국어 요건, 인턴십 필수 여부
7. 회사의 학업 병행 허용·학비 지원 제도

### 3.5 일정 시나리오 (기준일 2026-11-22)

## 4. 목표 수준 정의와 갭 분석

### 4.1 ‘동기에게 뒤처지지 않는 수준’의 측정 가능한 정의 (Exit Criteria)
입학 전 아래 12개를 통과하면 준비 완료로 본다. 앱의 ‘준비도’ 화면에 체크리스트로 구현한다.

1. 핵심 개념 300개를 각 60초 안에 비전공 독자에게 설명할 수 있다 (파인만 체크).
2. 신약개발 전주기(타깃 발굴~시판 후)를 단계별 목적·기간·비용·주요 실패 원인과 함께 그릴 수 있다.
3. PK 그래프에서 Cmax, Tmax, AUC, 반감기를 읽고 용량 변화의 효과를 설명할 수 있다.
4. 임상 논문 초록(NEJM·Lancet 수준)에서 디자인·1차 평가변수·효과크기·신뢰구간·한계를 5분 안에 정리할 수 있다.
5. 2×2 표에서 RR, OR, ARR, RRR, NNT를 계산하고 HR·p값·신뢰구간의 의미를 정확히 말할 수 있다.
6. 생존곡선(KM)과 포레스트 플롯을 해석하고 하위군 분석 과대해석을 지적할 수 있다.
7. FDA·EMA·식약처 허가 경로와 신속 프로그램의 차이를 표로 설명할 수 있다.
8. 국내 신약 급여 등재 흐름(허가→급여 평가→약가 협상→고시), 경제성평가(ICER·QALY), 위험분담제의 취지를 설명할 수 있다.
9. 기술수출 공시에서 총계약금액·계약금(업프론트)·마일스톤·로열티를 분리하고 ‘실제로 확정된 돈’을 말할 수 있다.
10. 바이오기업 재무제표에서 현금성자산, 영업현금흐름, 현금 소진 기간, 희석 가능성을 계산할 수 있다.
11. 보도자료 1건에서 과장 신호(레드플래그)를 5개 이상 찾고, 독립 전문가에게 던질 질문 3개를 만들 수 있다.
12. 학업계획서와 구술 예상 질문 60개에 대한 90초 답변을 갖추고, 모의 구술 자기 평가 80점 이상.

### 4.3 차별화 전략
동기들과 같은 지식으로만 경쟁하지 않는다. 지식 + 해석·전달 능력의 조합으로 경쟁한다. 그래서 모든 레슨에 ‘취재 노트(기자라면 무엇을 확인할까)’, 매주 ‘데스킹(기사 문장으로 써보기)’ 과제를 넣는다.

## 6. 학습과학 설계 원칙 (어떻게 해야 안 까먹는가)

각 원칙은 반드시 앱 기능으로 구현돼야 한다. 원칙만 있고 기능이 없으면 실패로 본다.

| # | 원칙 | 근거(대표 연구) | 앱 구현 |
|---|---|---|---|
| P1 | 인출 연습: 다시 읽기보다 떠올리기가 장기 기억을 만든다 | Roediger & Karpicke(2006); Dunlosky 등(2013)이 학습법 중 ‘높은 효용’으로 평가 | 레슨은 문제로 시작·중간·끝. 하이라이트·다시 읽기 기능 대신 ‘떠올려 보기’ 버튼 |
| P2 | 간격 반복: 나눠서 반복하면 망각 곡선이 완만해진다 | Ebbinghaus(1885); Cepeda 등(2006) 메타분석 | SRS 스케줄러(11.1), 목표 기억 유지율 90% |
| P3 | 연속 재학습: 서로 다른 날 여러 번 맞혀야 ‘아는 것’ | Rawson & Dunlosky의 successive relearning 연구 | 마스터리 승급은 ‘서로 다른 날 정답 횟수’로만 (11.2) |
| P4 | 교차 연습: 유형을 섞어 풀면 구분 능력이 생긴다 | Rohrer & Taylor(2007); Kornell & Bjork(2008) | W3부터 연습 세트는 최소 3개 도메인 혼합 |
| P5 | 바람직한 어려움 | Bjork(1994) | 예상 정답률 70~85% 대역으로 난이도 자동 조절(Elo, 11.3) |
| P6 | 사전 테스트: 배우기 전에 먼저 풀어보면 이후 학습이 강해진다 | Richland, Kornell & Kao(2009) | 레슨 전 사전 질문 3개(점수 미반영) |
| P7 | 생성 효과·자기설명 | Slamecka & Graf(1978); Chi 등의 자기설명 연구 | 파인만 박스: 독자에게 3문장으로 설명 → 모범 요약과 비교 |
| P8 | 정교화 질문 | Dunlosky 등(2013) | 카드 뒷면 ‘왜 그런가?’ 확장 |
| P9 | 이중 부호화·멀티미디어 원리 | Paivio; Mayer | 개념마다 도식 1개(SVG), 글과 그림을 같은 화면에 |
| P10 | 인지부하 관리·예제 풀이 효과 | Sweller; 숙련도 역전 효과(Kalyuga) | 초급은 풀이 예제 → 부분 빈칸 → 독립 풀이(점진적 제거). 숙련되면 예제 생략 |
| P11 | 확신도 기반 메타인지 보정 | 학습 판단 연구; 고확신 오류 교정 효과(Butterfield & Metcalfe, 2001) | 답 공개 전 확신도 입력. ‘확신했는데 틀림’은 최우선 복습 |
| P12 | 숙달 학습 | Bloom(1968, 1984) | 단원 시험 80% 미만이면 ‘보완 루프’ 자동 생성 |
| P13 | 선행조직자: 큰 그림 먼저 | Ausubel | W1에 전주기 지도. 모든 레슨 상단에 ‘지도에서 지금 위치’ |
| P14 | 구체적 예시와 전이 | 전이 학습 연구 | 개념마다 가상 보도자료·공시 속 실제 쓰임 예시 1개 |
| P15 | 습관 설계: 실행 의도·작은 습관 | Gollwitzer(1999); Fogg | 온보딩에서 ‘언제·어디서·무엇 다음에’ 입력, 10분 미니 세션 버튼 |
| P16 | 수면과 기억 공고화 | 수면-기억 연구 | 취침 전 10분 복습 모드 |
| P17 | 즉시·설명형 피드백 | 형성평가 연구 | 정답뿐 아니라 각 오답 선택지가 왜 틀렸는지 표시 |
| P18 | 오류 원인 분류 | 오류 분석 | 틀리면 원인 태그(개념 모름/헷갈림/계산 실수/문제 오독) → 처방을 다르게 |

효과가 낮아 주 학습법으로 쓰지 않는 것: 형광펜 긋기, 다시 읽기, 요약만 하기, 긴 영상 수동 시청. 앱에 하이라이트 기능을 넣지 않는다.

### 6.1 하루 세션의 과학적 구성
복습(인출·간격) → 사전 질문(사전 테스트) → 레슨(이중 부호화·예제) → 레슨 중 확인 질문(인출) → 교차 연습(교차·바람직한 어려움) → 오늘의 보도자료(전이) → 마감 노트(생성·메타인지·실행 의도)

### 6.2 오류 원인별 처방
| 원인 | 처방 |
|---|---|
| 개념 모름 | 해당 레슨 청크 다시 보기 링크 + 카드 간격 초기화 |
| 헷갈림 | 혼동 개념 쌍 비교 카드 자동 생성(예: OR vs RR), 다음 연습에 대조 문항 2개 |
| 계산 실수 | 같은 유형 풀이 예제 → 숫자만 바꾼 문항 2개 |
| 문제 오독 | 문두 핵심어 표시 연습, 기록만 하고 간격은 유지 |

### 7.1 결합 결과 — 핵심 컨셉 ‘PIPELINE’
학습자의 개념 하나하나를 ‘신약 후보물질’처럼 다룬다. 개념은 탐색 → 전임상 → 1상 → 2상 → 3상 → 허가 → 시판 후 단계를 거쳐 ‘승인’된다. 메인 화면은 제약사 IR 자료의 파이프라인 차트 모양이다. 학습 과정 자체가 개발 단계 감각을 몸에 익히는 은유가 된다. 복습에서 틀리면 ‘안전성 신호’로 단계가 내려간다.

| 결합 요소 | 출처 사례 | 구현 위치 |
|---|---|---|
| 파이프라인 지도 + 단 하나의 다음 행동 버튼 | Duolingo + Khan | 파이프라인 탭, 오늘 탭 |
| SRS + 연속 재학습 승급 | Anki | 복습 엔진 |

| 다중 모드 | Quizlet | 복습 탭 |
| 하루 1건 의식 | Wordle | 오늘의 보도자료 |
| 적응형 난이도 + 러시 | Chess.com | 연습, 게임 |
| 근접도 추정 게임 | GeoGuessr | 딜 게서 |
| 일상 독서 연결 | Readwise | 스크랩 인박스 |
| 진단·준비도 수치 | 산타토익 | 나 탭 |
| 3개 링 | Apple 피트니스 | 오늘 탭 |

### 7.2 게이미피케이션 원칙
- 보상은 ‘학습 행동’에만 준다(접속·클릭에는 주지 않는다).
- 경쟁 상대는 ‘지난주의 나’. 타인 리그 없음.

- XP: 복습 1장 1, 신규 카드 2, 문제 정답 2(오답 후 재도전 정답 1), 레슨 완료 10, 파인만 박스 5, 데스킹 과제 20, 단원 허가 50.

### 8.5 게임
#### 8.5.1 오늘의 보도자료 (Wordle형, 하루 1건)
- 가상 보도자료 1건(400~700자)을 문장 단위로 표시. 숨은 레드플래그 3~5개.
- 6번의 선택 기회 안에 레드플래그 문장을 고른다. 결과 색: 초록(레드플래그), 노랑(의심할 만하나 핵심 아님), 회색(문제 없음).
- 종료 후: 레드플래그별 해설, 독립 전문가에게 물을 질문 모범안, 정확하게 다시 쓴 리드 문장.
- 결과 그리드(이모지 블록) 클립보드 복사.
- 날짜를 시드로 같은 날엔 같은 문제.
- 레드플래그 분류(콘텐츠 생성 시 사용): 상대위험만 제시 / 대리지표를 치료 효과처럼 표현 / 동물·세포 결과를 사람 효과처럼 / 단일군·소규모 결과 일반화 / 1차 평가변수 대신 2차·하위군 강조 / 통계적 유의성과 임상적 의미 혼동 / 총계약규모를 확정 수익처럼 / 임상 승인(IND)을 성공처럼 / 근거 없는 수식어(세계 최초·획기적·완치) / 비교 대상 부재 / 안전성 정보 누락 / 연구비 출처·이해상충 미기재 / 시장 규모 과장 / 일정 낙관.

#### 8.5.2 딜 게서 (GeoGuessr형)
- 단서 카드 3~5장(가상 계약 개요, 모달리티, 개발 단계, 적응증, 상대 회사 규모).
- 질문 예: 총계약규모 중 계약금 비율 추정 / 이 단계 후보물질의 허가 도달 확률 추정 / 확률 가중 기대 가치 추정.
- 최대 5,000점, 근접도에 따라 감소(11.5). 정답 공개 시 근거와 참고 범위(출처 포함). 하루 5라운드.

#### 8.5.3 속보 러시 (퍼즐 러시형)
- 3분, 오답 3번이면 종료. 약어·정의·단계·숫자 감각의 빠른 문항. 개인 최고 기록만 표시.

#### 8.5.4 매칭 (Quizlet 매치형)
- 12쌍 짝 맞추기: 약어↔정의, 모달리티↔작용기전, 제도↔국가. 기록 시간 표시.

#### 8.5.5 파이프라인 정렬
- 단계·절차 카드 순서 맞추기: 신약개발 단계, FDA 심사 흐름, 국내 급여 등재 흐름, 기술이전 협상 단계.

### 8.6 시험
- 진단평가(W0): 도메인당 최대 8문항, 적응형으로 약 90문항 안에서 종료. 결과로 단원별 ‘건너뛰기 가능’ 표시(Khan 코스 챌린지 방식). 건너뛴 단원의 카드도 SRS에는 넣는다.
- 주간 미니 시험: 20문항, 이번 주 60% + 누적 40%.
- 단원 시험: 단원 허가 관문(80%).
- PBJ 인증 모의시험: 12.5 블루프린트. 시험 모드는 해설 숨김·시간 제한. 종료 후 영역별 점수와 오답 노트 자동 생성.
- 모의 구술: 질문 은행에서 무작위 5문항, 각 30초 준비 + 90초 답변, 브라우저 녹음(MediaRecorder, 로컬 저장), 재생 후 루브릭 자기 평가(정확성·구조·구체성·전문용어·시간 준수).
- 학업계획서 워크숍: 배경(기자 경력) → 문제의식 → 학업 목표(트랙) → 연구 관심 → 졸업 후 계획의 단계별 입력 폼, 버전 저장, 글자 수 표시, AI 첨삭 프롬프트 복사.
- 입시 체크리스트: 3.4의 7개 항목을 학교별로 체크.

### 8.7 인터랙티브 랩 (Brilliant형)
각 랩 = 조작 위젯 + 안내 과제 3~5개 + 해설.
| 랩 | 조작 | 학습 목표 |
|---|---|---|
| PK 시뮬레이터 | 용량, 투여 간격, 반감기, 흡수 속도 슬라이더 → 혈중농도 곡선 | Cmax·Tmax·AUC·정상상태·축적 |
| 용량-반응 곡선 | EC50, Emax, 힐 계수 | 효능 vs 효력, 치료지수 |
| 2×2 표 계산기 | 사건 수 입력 → RR, OR, ARR, RRR, NNT | 상대·절대위험 차이 체감 |
| KM 곡선 판독기 | 가상 생존곡선 2개, 시점 슬라이더 | 중앙 생존기간, HR 직관, 곡선 교차의 의미 |
| 포레스트 플롯 판독기 | 하위군 점추정·신뢰구간 | 1선 교차, 하위군 과대해석 |
| 단계 성공확률 사다리 | 단계별 전환 확률 | 누적 허가 확률 |
| 딜 구조 계산기 | 계약금·단계별 마일스톤·로열티율·성공확률·할인율 | 총계약규모 vs 확정액 vs 확률가중 가치(간이 rNPV) |
| ICER 계산기 | 두 대안의 비용·QALY | 증분비용효과비와 임계값 비교 |
| 현금 소진 계산기 | 현금성자산, 분기 영업현금흐름 | 런웨이(개월), 자금조달 필요 시점 |
| 희석 계산기 | 기존 주식 수, 신주 수, CB 전환가 | 지분 희석률 |

### 8.8 준비도·분석 (나 탭)
- 준비도 지수(도메인별 0~100) = 0.5 × 마스터리 비율 + 0.3 × 최근 4주 정답률(Elo 보정) + 0.2 × 기억 유지율. 레이더 차트에 목표선(대학원 1학기 기준 70) 표시.
- 보정 그래프: 확신도별 실제 정답률.
- 기억 유지율: 지난 30일 복습 정답률(목표 85~92%).
- 오류 원인 분포, 학습 시간 히트맵(잔디형), 주간 회고 기록.
- 예측은 반드시 범위로 표시(예: 64 ± 8).

### 8.9 스크랩 인박스 (Readwise형)
- 업무 중 본 기사 문장·용어·의문을 빠르게 입력(제목, 메모, 출처 URL, 내 질문).
- 정리 화면에서 직접 ‘질문-답’ 카드로 바꾼다(생성 효과) → SRS 투입.
- 주간 데스크에서 인박스 비우기.

### 8.10 설정
목표 면접일, 시나리오(A/B), 요일별 학습 시간, 하루 신규 카드 수(기본 8), 최대 복습 수(기본 80), 목표 유지율(기본 0.90), 버퍼 주간, 하루 시작 시각(기본 04:00), 테마(라이트/다크/자동), 글자 크기, 콘텐츠 팩 가져오기·관리, 데이터 백업(JSON 내보내기)·복원, 매일 알림용 캘린더 파일(.ics) 생성, 초기화.

## 10. 기술 구조와 데이터 모델

### 10.1 기술 스택
- 단일 index.html (HTML + CSS + 바닐라 JavaScript). 빌드 도구·서버 불필요. file:// 로 열어도 동작.
- 저장: IndexedDB(콘텐츠, 학습 기록, 녹음). localStorage는 설정만. 저장소 래퍼로 감싸 교체 가능하게.
- 콘텐츠: JSON 콘텐츠 팩을 ‘가져오기’(파일 선택 또는 텍스트 붙여넣기)로 IndexedDB에 저장. 팩 단위 버전 관리. 같은 id는 덮어쓰되 학습 기록은 보존.
- 선택: PWA(manifest + service worker)로 iPhone 홈 화면 설치. 정적 호스팅(GitHub Pages 등) 시 사용.
- 기기 간 이동: 1차 버전은 JSON 백업 내보내기/가져오기. 파일명에 날짜.
- 외부 라이브러리 최소화. 차트는 SVG 직접 렌더링. (선택) 간격 반복 고도화 시 ts-fsrs.
- 본문은 경량 마크다운(굵게, 목록, 표, 인용) 렌더러 직접 구현. 사용자 입력과 콘텐츠 문자열은 반드시 이스케이프(XSS 방지). 팩의 SVG는 허용 태그만 남기는 정화 후 삽입.

### 10.2 데이터 모델 (TypeScript 표기, 실제 저장은 JSON)
```ts

type Phase = 'discovery' | 'preclinical' | 'p1' | 'p2' | 'p3' | 'approved' | 'p4';
type Confidence = 'unknown' | 'unsure' | 'sure';
type ErrorCause = 'concept' | 'confusion' | 'calculation' | 'misread';

interface ContentPack {
  packId: string;        // 예: 'W04-pk-basics'
  version: string;       // 'YYYY-MM-DD.n'
  week: number;          // 0~36
  domains: string[];     // ['D03']
  title: string;
  units: Unit[];
  lessons: Lesson[];
  cards: Card[];
  items: Item[];
  cases?: Case[];
  dailyReleases?: PressRelease[];
  dealRounds?: DealRound[];
  exams?: Exam[];
  glossary?: GlossaryEntry[];

}

interface Unit { id: string; domain: string; title: string; order: number; lessonIds: string[]; examId?: string; }

interface Lesson {
  id: string; unitId: string; title: string; minutes: number;
  objectives: string[];                 // 블룸 동사로 시작
  pretestItemIds: string[];             // 3개
  chunks: { id: string; markdown: string; diagram?: Diagram; checkItemId: string; }[];
  boxes: { kind: 'reporter' | 'misconception' | 'numbers'; markdown: string; }[];
  feynman: { prompt: string; modelSummary: string; mustInclude: string[]; };
  cardIds: string[];
  sourceIds: string[];
}

interface Diagram { kind: 'svg' | 'flow' | 'table' | 'chart'; svg?: string; spec?: any; caption: string; alt: string; }

  id: string; domain: string; axis: Axis[]; tags: string[];   // 핵심 개념은 tags에 'core'

  back: string;             // 1~3문장
  why?: string;             // 정교화: 왜 그런가
  example?: string;         // 기사·공시 속 쓰임
  confusables?: string[];   // 헷갈리는 카드 id
  en?: string; abbr?: string;

  id: string;
  type: 'mcq' | 'multi' | 'cloze' | 'short' | 'order' | 'match' | 'numeric' | 'estimate' | 'hotspot' | 'chart' | 'case' | 'oral' | 'desk';

  exhibit?: Diagram;                    // chart·case용 자료
  explanation: string;
  rubric?: { criterion: string; points: number; }[];   // short·oral·desk
  hint?: string;
  sourceIds: string[]; asOf?: string; needsVerification?: boolean;
}

  id: string; date: string; company: string;          // company는 가상 기업
```

## 11. 알고리즘

### 11.1 간격 반복 스케줄러 (기본 SM-2 변형, 선택 FSRS)
평가: 1 다시, 2 어려움, 3 알맞음, 4 쉬움. 초기 ease 2.5, 최소 1.3.
- 신규 카드 학습 단계: 1분 → 10분(세션 내 재출제) → 1일.
- 복습 카드:
  - 다시(1): lapses +1, ease −0.20, interval = 1일, 세션 내 10분 뒤 재출제, phase 한 단계 강등(최저 p1) = ‘안전성 신호’
  - 어려움(2): interval = max(1, round(interval × 1.2)), ease −0.15
  - 알맞음(3): interval이 0이면 1, 1이면 3, 그 외 round(interval × ease)
  - 쉬움(4): interval = round(interval × ease × 1.3), ease +0.15
- 분산: 간격 3일 이상이면 ±5% 무작위(같은 날 몰림 방지).
- 최대 간격 기본 120일. 목표 면접일이 있으면 다음 복습이 면접일을 넘는 core 카드는 면접 7~10일 전으로 당긴다.
- 부하 관리: 향후 7일 만기 예측이 하루 최대 복습 수의 1.5배를 넘으면 신규 카드 수를 자동 50% 감소하고 알린다.
- 밀린 복습 정렬: (오늘 − 만기일) ÷ interval 이 큰 순(가장 잊었을 위험이 큰 것부터).
- 확신도 반영: ‘확실’인데 오답 → misconception = true, 다음날 강제 재출제. ‘모름’인데 정답 → 평가를 최대 ‘어려움’으로 제한(운 좋은 정답 방지).
- 선택(FSRS): ts-fsrs 사용 시 request_retention = 설정의 목표 유지율(기본 0.9). 아래 마스터리 규칙은 그대로 유지.

### 11.2 마스터리(개발 단계) 승급 규칙 — 카드 단위
| 단계 | 조건 |
|---|---|
| 탐색 | 팩에 존재, 아직 미노출 |
| 전임상 | 레슨 또는 사전 질문에서 노출 |
| 1상 | 노출 후 하루 이상 지난 뒤 첫 정답(평가 3 이상) |
| 2상 | 서로 다른 2일에 정답, 그중 1회는 카드가 아닌 다른 문항 유형 |
| 3상 | 서로 다른 3일에 정답 + 적용 수준(bloom apply 이상) 문항 정답 |
| 허가 | interval 21일 이상 상태에서 정답 + 단원 시험에서 해당 개념 정답 |
| 시판 후 | interval 60일 이상 상태에서 정답. 이후 오답 시 ‘안전성 신호’로 2상 강등 |
단원 단계 = 소속 카드 단계의 하위 25% 지점(약한 고리 기준). 단원 ‘허가’에는 단원 시험 80% 이상 + 파인만 박스 완료가 추가로 필요.

### 11.3 적응형 난이도 (Elo)
- 학습자 도메인별 레이팅 R(초기 1000), 문항 난이도 D(초기 800 + 100 × difficulty).
- 예상 정답확률 P = 1 / (1 + 10^((D − R) / 400)).
- 결과 s(0~1) 반영: R ← R + Ku × (s − P), D ← D − Ki × (s − P). Ku = 32(그 도메인 시도 30회 이후 16), Ki = 16(그 문항 시도 20회 이후 8).
- 출제: P가 0.70~0.85인 문항 우선, 부족하면 범위를 넓힌다. 3연속 오답이면 다음 문항은 P ≥ 0.85에서(좌절 방지).

### 11.4 교차 연습 세트 생성
1. 후보 풀: 오늘 레슨 문항 / 최근 14일 문항 / 그 이전 문항.
2. 비율 40/30/30, 최소 3개 도메인(W3 이후), 같은 카드 연속 금지, 같은 유형 3연속 금지.
3. 각 풀에서 Elo 목표 대역으로 고른 뒤 섞는다.

### 11.5 추정 점수 (딜 게서·estimate)
- 오차 e = |log10(추정 ÷ 정답)| (logScale), 선형이면 |추정 − 정답| ÷ |정답|.
- 점수 = round(5000 × exp(−3 × e)). 오차 5% 이내는 5000.

### 11.6 준비도 지수의 범위
표시 = 지수 ± round(100 ÷ sqrt(해당 도메인 최근 4주 시도 수 + 4)).

### 11.7 스트릭
하루 인정 조건: 복습 대기열 0 또는 10분 미니 세션 완료. 월 2회 휴가권 자동 사용. 끊기면 이후 3일간 XP 1.5배 ‘재개 보너스’.
