## 감수 방법
1. `python3 tools/check_pack.py 파일` — 형식·루브릭 점검.
2. 새 대화(또는 다른 AI)에 감수 프롬프트와 파일을 붙여 넣고 수정 패치를 받는다.
3. 패치 반영 → 무작위 사실 3개를 출처와 직접 대조 → `review`를 `reviewed`로 → `site/packs/`에 다시 복사 → 앱에서 ‘기본 콘텐츠 불러오기·업데이트’.
