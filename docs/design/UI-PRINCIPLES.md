# UI 원칙 — 애플식 디자인 × 웹게임 로직 (D018·D019, D016 대체)

> 2026-11-22 사용자 지시: ‘업무 프로그램·관리자 설정 페이지’가 아니라 웹게임처럼. 매일 들어와 내 캐릭터를 보고, 간결하고 간단한 동작으로, 중독적으로. 버튼은 적게, 기능은 체계적으로 다 들어가게. 디자인은 애플식, 로직은 성공한 웹게임을 모방.

## 한 줄 컨셉

**나는 수습기자다.** 매일 홈에서 내 기자 캐릭터를 만나고, 큰 버튼 하나로 ‘취재’(카드 복습)를 나간다. 카드 한 장마다 소리·숫자·콤보가 튀고, 끝나면 XP가 차오르고 연차가 오르며 장비가 생긴다. 놓친 카드는 도감의 ‘?’로 남고, 지도에는 다음 칸이 깜박인다.

|---|---|---|

## 게임 3종 — Wordle · 2048 · Little Alchemy 2 (D019)

> 2026-11-22 사용자 지시: 콘텐츠가 정적이고 재미없다. Wordle, 2048, Little Alchemy 2의 장점만 모방해 재미를 녹여 넣어라. 공부하면서도 재미있을 수 있다. 코스 2를 먼저 다 진행한 뒤 코스 1.

| 원작 | 왜 중독적인가 | 이 앱에서 | 무엇을 배우나 |
|---|---|---|---|

공통 고리: **발견 = 카드가 취재 덱에 들어감**. 게임에서 처음 본 지식은 다음 날부터 간격 반복으로 다시 떠올린다(놀기 → 배우기 → 굳히기). 홈의 큰 버튼은 지금 할 일 하나만 고른다: 밀린 취재 → 오늘의 진단 → 오늘의 숫자 → 새 발견.

### 코스 순서 (D019)

HEALTH BEAT(코스 2)가 먼저다. PIPELINE(코스 1) 카드는 잠겨 취재에 나오지 않고, 지도는 미리보기로만 본다(나 → 코스). HEALTH BEAT를 마친 뒤 나 → 설정 → 코스에서 연다. 열어도 덱은 코스 2 카드가 먼저다.

### 탭 (5개)

홈 · 발견(인체 연금술) · 근거(근거 2048) · 도감(모든 카드, 미발견은 ‘?’와 어디서 열리는지) · 나(프로필·코스·장비·출석부·설정). 오늘의 퍼즐 2개는 홈 타일에서 들어간다.

## 화면 구조 (D018 당시 탭 4개 — D019에서 위 5개로 바뀜)

| 탭 | 역할 | 주 행동 |
|---|---|---|
| 홈 | 캐릭터·말풍선·연차·XP, 오늘의 퀘스트 3링, 주간 불꽃 7칸, 다음 일정 D-day | 취재 시작(끝나면 ‘새 카드 5장 더’) |
| 지도 | 주차별 레슨 길, 진행 링, 보스 시험 | 레슨 칸 → ‘이 레슨 카드로 취재’ |
| 도감 | 발견 수 큰 숫자, 기억 강도 막대, 카드 타일 | 카드 눌러 앞뒷면·다음 복습 보기 |
| 나 | 프로필, 연속·최장·발견·XP, 장비 9개, 12주 출석부 | (설정으로 들어가는 줄 하나) |

관리 기능(콘텐츠 팩·백업·복원·테마·학습량)은 **나 → 설정** 한 곳에 모았다. 첫 화면들에는 관리 버튼이 없다.

## 취재(복습) 한 판의 손동작

1. 앞면을 보고 떠올린다.
2. 확신만큼 누른다: **모름 · 애매 · 확실** → 카드가 뒤집힌다(확신도 입력 = 뒤집기, 버튼 한 번 절약).
3. 정답을 보고 평가한다: **다시 · 어려움 · 알맞음 · 쉬움**, 버튼 아래 다음 간격(1분·10분·3일…).
4. +XP·콤보·특종이 튀고 다음 카드. 진행 막대가 찬다. 끝나면 결과 화면.

키보드: Enter/Space 시작·뒤집기·알맞음, Q/W/E 확신도, 1~4 평가, Esc 그만하기(그때까지 결과 저장).

## 지킬 규칙

1. 화면마다 큰 버튼은 하나. 나머지는 탭·카드·줄.
2. 모든 행동에 즉시 피드백: 소리(직접 합성, 설정에서 끔), 숫자 팝업, 카드 움직임, 진동 지원 기기는 짧은 진동.
3. 보상은 학습 행동에만(기획안 1의 7.2): 복습 1, 새 카드 2, 콤보 10마다 +2, 특종 2배, 퀘스트 3개 +10, 재개 보너스(끊긴 뒤 3일 1.5배).
4. 손실 회피는 다정하게: 연속일은 월 2회 휴가권으로 자동 보호, 끊겨도 재개 보너스. 실패해도 막지 않는다(하트·잠금 없음).
5. 숫자는 크게, 라벨은 작게(tabular-nums). 색은 의미에만: 파랑 = 행동, 초록 = 정답·완료, 주황 = 불꽃·주의, 빨강 = 다시·착각, 금색 = XP·보스·특종.
6. 애플식: 시스템 글꼴, 큰 제목, 둥근 카드(18~28px), 부드러운 그림자, 반투명 탭바, 라이트·다크·자동, 44px 이상 터치 영역.
7. 움직임은 짧고 탄력 있게(0.2~0.5초, 스프링 곡선). ‘동작 줄이기’ 설정이면 모두 끈다.
8. 외부 이미지·폰트·소리 파일 없음: 캐릭터·아이콘은 직접 그린 SVG, 소리는 Web Audio 합성.
9. 의학 내용은 게임이어도 정확성 우선: 감수 전 배지, 확인 필요 태그는 취재 화면에도 보인다.

## 캐릭터·연차·장비

- 연차: Lv 1 수습기자 → 3 1년차 → 5 2년차 → 8 3년차 → 11 5년차 → 15 전문기자 → 20 차장 → 25 부장 → 30 데스크. 레벨 n → n+1에 40 + 20n XP(하루 50 XP 안팎이면 36주 과정 끝 무렵 데스크).
- 장비(레벨에 따라 캐릭터에 그려짐): 프레스 목걸이(1), 취재 수첩(2), 귀에 꽂은 볼펜(4), 동그란 안경(6), 녹음기(9), 트렌치코트(13), 헤드셋(17), 넥타이(22), 데스크 머그(30).

## 이전 원칙(D016)에서 남긴 것

한 화면 한 행동, 의미 있는 색, 숫자 키 탭 이동(1~4), 고정폭 숫자, 4의 배수 간격, 시트·토스트.

## 사람 확인

Mac Safari·Chrome, iPhone Safari(라이트·다크)에서: 캐릭터가 귀여운지·어색한지, 홈 첫 화면에 큰 버튼이 보이는지, 취재 화면에서 엄지로 버튼이 편한지, 소리가 거슬리지 않는지(설정에서 끔), 결과 화면의 숫자 애니메이션.
