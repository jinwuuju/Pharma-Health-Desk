# 초안 (감수 대기)

생성은 끝났지만 감수 전인 콘텐츠다(D015). 여기 있는 파일은 앱 기본 탑재(`site/packs/`)에 넣지 않는다.

| 파일 | 내용 | 감수 프롬프트 |
|---|---|---|
| `canon/master-index.json` | 코스 2 마스터 색인 492행 | 기획안 2의 18.6 |
| `registry/stats-001.json` | 코스 2 통계 시드 34건 | 기획안 2의 18.6 + 출처 대조 |
| `packs/pipeline/W00.json` | 코스 1 W0 진단평가 95문항 | 기획안 1의 14.5 |

순서
1. `python3 tools/check_pack.py drafts/...json` — 형식·루브릭 점검.
2. 새 대화(또는 다른 AI)에 감수 프롬프트와 파일을 붙여 넣고 수정 패치를 받는다.
3. 패치 반영 → 무작위 사실 3개를 출처와 직접 대조.
4. 같은 하위 경로로 `data/`에 옮기고 STATUS에 기록. 앱 기본 탑재가 필요하면 `site/packs/`로 복사.

통계 시드 미확인 목록(만들지 않은 값)
- 2024년 진료분(2025-06 발표) 입원 4위 ‘기타 추간판장애’ — 원자료 미확인.
- U4·U5·U8~U12의 다빈도 순위·진료인원 — 다음 배치.
- GLP-1 비만치료제 시장·국산 제품 출시 앵커(기획안 2의 6장) — 다음 배치.
- 다빈도 통계 ‘진료인원’의 중복 처리 기준 — 심평원 원문 확인.
- 2025년 생명표, 2026 만성질환 현황과 이슈 발표일(2026-12로 추정) — 발표 뒤 갱신.
